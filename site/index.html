Tours que no se rompen con modales

Guías sin dependencias que esperan al modal y dejan practicar.

Empezar
npm i nexus-tours
tour.ts
import { Tour } from 'nexus-tours'

new Tour({
  steps: [
    { element: '#nuevo', title: 'Crea un cliente' },
    { before: abrirModal, element: '#nombre',
      title: 'Ponle nombre' },
    { element: '#guardar', title: 'Guarda',
      after: cerrarModal },
  ],
}).start()
El modal se abre solo y el tour lo espera

Por qué

Guías sin dependencias que esperan a que el modal exista, viven dentro del <dialog>, no chocan con tu CSS y dejan practicar con datos de ejemplo.

Modales de verdad

Espera elementos animados o asíncronos, se monta dentro del <dialog> y se recupera si el modal se cierra y se reabre.

Aislado de tu CSS

Shadow DOM: tu página no lo rompe ni él rompe tu página. Se personaliza con variables, ::part() y temas.

Modo práctica

Responde fetch con datos de ejemplo y bloquea escrituras reales mientras la persona aprende.

Accesible

Foco atrapado y restaurado, anuncios para lector de pantalla, teclado, derecha a izquierda y movimiento reducido.

Checklist y constructor

Lista de primeros pasos que recuerda el avance y un constructor visual para armar tours sin escribir código.

Vue, React y CDN

Wrappers de poco más de 1 KB, seguros con StrictMode, y un solo <script> si no usas bundler.
