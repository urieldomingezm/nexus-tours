nexus-tours
Demo Uso

Tours que no se rompen con modales.

Guías de producto sin dependencias (~8 KB). Esperan a que el modal exista, viven dentro del <dialog>, no chocan con tu CSS y dejan practicar con datos de ejemplo.

Cómo se usa npm i nexus-tours

Modales de verdad

Espera elementos animados o asíncronos, se monta dentro del <dialog> y se recupera si el modal se cierra y reabre.

Aislado de tu CSS

Shadow DOM: tu página no lo rompe ni él rompe tu página. Personalízalo con variables, ::part() y temas.

Modo práctica

Responde fetch con datos de ejemplo y bloquea escrituras reales mientras el usuario aprende.

Accesible

Foco atrapado y restaurado, anuncios para lector de pantalla, teclado, RTL y movimiento reducido.

Vue y React

Wrappers de ~1 KB: componente y hook/composable, seguros con StrictMode.

Ligero

Núcleo ~8 KB gzip, datos de ejemplo 2 KB, temas 0.5 KB, sin dependencias.

Pruébalo aquí

El mini CRM de la derecha tiene un modal animado con contenido que carga después: el caso que rompe a otras librerías.

Con modo práctica activo, guardar un cliente no toca los datos reales; al terminar el tour todo vuelve.
